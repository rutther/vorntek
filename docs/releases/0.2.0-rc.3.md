# Vorntek 0.2.0-rc.3 — complete clean-download verification setup

This candidate supersedes `0.2.0-rc.2`. Rc.2 correctly made the root Python suite
work without Git metadata, but anonymous acceptance found that the documented Node
command did not first install the locked `flow-ui` dependencies and therefore could
fail with a missing `jsdom` module in a clean download.

The bilingual README and development guide now install the locked Node dependency
tree before running root browser scripts, the complete guided-workspace suite and
the production UI build. A documentation contract enforces that ordering. Python
archive tests retain the explicit Git-only skips introduced in rc.2.

This correction changes verification and operator guidance, not application
behavior. It does not enable external integrations or deploy either running site.
Install through README.md or README.zh-CN.md, create unique secrets and an
administrator, and follow docs/UPGRADE.md for existing installations.

External Meta/Google/email/WhatsApp delivery remains off by default. Mocked
transports do not prove provider reception, attribution or deduplication. Prebuilt
container images, multi-node failover, SLA promises, SaaS billing and new
WhatsApp/MFA features remain outside this release scope.
