# Vorntek0.2.0-rc.1 — website and business workspace

This source candidate contains a self-hosted industrial B2B website and business
workspace: configurable inquiries, desktop CRM/tasks, recoverable lead trash,
guided workflows with diagrams/illustrations, multiple workflow instances,
article/3D editing and immutable website publication/recovery.

The replaceable industrial example has six equipment concepts, three applications,
engineering guides, GLBs, structural videos, context images and specifications.
Its explicit initializer adds media, disabled profiles and English/Chinese/Arabic
engineering drafts. It does not create credentials or auto-publish content.

Install through README.md or README.zh-CN.md. Create your administrator and unique
secrets. Existing installations follow docs/UPGRADE.md while preserving project,
volume and secret identities, with a verified paired backup. SQL appends through
0043; legacy compatibility names remain. Downloads are bound to an exact commit
and verified by SHA256SUMS. Build the supplied Compose files; prebuilt images are
not included.

External Meta/Google/email/WhatsApp delivery is off by default. Mocked transports
do not prove provider reception, attribution or deduplication. Administration
targets PC browsers; public pages retain mobile and RTL support. Multi-node
failover, SLA promises, SaaS billing and new WhatsApp/MFA features are outside scope.

Actual PR/CI/Tag and independent download acceptance links accompany the GitHub
Release after completion. These prepared notes do not assert publication yet.
