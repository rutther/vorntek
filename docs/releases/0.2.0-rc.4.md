# Vorntek 0.2.0-rc.4 — fresh-install browser fixture alignment

This candidate supersedes `0.2.0-rc.3`. Anonymous browser acceptance of rc.3
showed that the isolated synthetic fixture created the historical `industrial`
form category, while documented fresh installations create a `general` inquiry
form. The stale fixture could therefore display legacy category-specific fields
during an otherwise current product review.

Rc.4 makes the fixture use the documented fresh-install contract and adds a
regression test for that choice. It does not rewrite or silently convert existing
legacy forms, remove compatibility behavior, enable external integrations, or
deploy either running website.

Install through README.md or README.zh-CN.md, create unique secrets and an
administrator, and follow docs/UPGRADE.md for an existing installation. External
Meta/Google/email/WhatsApp delivery remains disabled by default. Prebuilt images,
multi-node failover, SLA promises, SaaS billing and new WhatsApp/MFA features
remain outside this source release.
