# Vorntek 0.2.0-rc.2 — source archive verification fix

This candidate supersedes `0.2.0-rc.1`. The earlier release passed application,
PostgreSQL and Compose CI and its anonymous downloads matched their published
checksums, but the documented root test command ended with eight errors in a
downloaded archive because `.git` metadata is intentionally excluded.

In rc.2, Git-history and tracked-input integrity tests run unchanged in repository
checkouts and report explicit skips in source archives. All archive-safe root tests,
JavaScript checks and application suites remain active. This is a verification and
operator-experience correction; it does not change application behavior, enable
external integrations or deploy either running website.

Install through README.md or README.zh-CN.md. Create your own administrator and
unique secrets. Existing installations follow docs/UPGRADE.md with paired database,
file and secret backups. Downloads are bound to an exact commit and SHA256SUMS;
prebuilt container images are not included.

External Meta/Google/email/WhatsApp delivery remains off by default. Mocked
transports do not prove provider reception, attribution or deduplication. Multi-node
failover, SLA promises, SaaS billing and new WhatsApp/MFA features remain outside
this release scope.
