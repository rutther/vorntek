## Anonymous installation and tests

`scripts/configure.py` created new local configuration and file-backed secrets.
No source checkout, developer virtual environment or `node_modules` directory was
reused. Python 3.12.14 installed the locked requirements; the isolated flow UI
installed 126 packages with `npm ci`.

- Root Python: 116 passed, including eight explicit archive-safe Git-only skips.
- Application: 1361 passed; 140 documented SQLite conditional skips.
- Root JavaScript: 51 passed.
- Guided-loop JavaScript: 208 passed.
- Vite production build: passed.
- `pip check`: no broken requirements.
- `pip-audit`: no known vulnerabilities after updating the fresh environment's
  bundled pip 25.0.1 to pip 26.2.1. The flagged package was the installer, not an
  application lock dependency.
- `npm audit --audit-level=high`: zero vulnerabilities.

## Browser acceptance

An ephemeral loopback-only SQLite fixture blocked non-loopback Python sockets,
disabled scheduled tasks and all external writers, and used synthetic identities.
The credential file was deleted on shutdown.

Observed in the actual browser:

1. The public fresh-install form used the `general` contract: name plus optional
   email, phone, company, region and request; no legacy industrial category field.
2. A synthetic inquiry returned `Inquiry received` and appeared in CRM with its
   message, consent and technical submission evidence.
3. The lead could be selected, moved to recoverable trash with a reason, restored,
   and observed again in the active queue. Tasks and event operations loaded.
4. Two Meta website closed-loop instances of the same type were created and could
   be switched independently. The ten-step guide, reference illustration and
   cross-system swimlane diagram were visible.
5. Article and asset workspaces loaded. The industrial product page started its
   interactive 3D viewer and visibly rendered the equipment model.

Fixture shutdown evidence recorded one synthetic lead, two fixture companies,
zero imports, zero exported jobs and no external I/O.

## Industrial example boundary

The public industrial website, equipment media and bundled product GLB were
reconstructed from the public archive and rendered without private assets. The
optional industrial database pack's plan reported three articles, six disabled
3D profiles and fifteen files. Its canonical write lifecycle is PostgreSQL-only
and passed tag CI. The Windows anonymous host had no Docker executable, so a local
SQLite write attempt was rejected by the missing canonical business tables and is
not represented as a successful installation.
