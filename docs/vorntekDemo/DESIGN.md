# Corporate direction and implementation

Help industrial buyers identify equipment, inspect arrangement and constraints,
then submit a contextual production inquiry. Retain Vorntek blue/navy identity,
white navigation, light factory surfaces and graphite equipment. Manrope Latin is
self-hosted; Chinese/Arabic use available system glyphs. No invented proof points.

Homepage: environment and equipment families. Product: selection/gallery,
technical data/dimension envelope, original3D/video, applications and questions.
Company/technology/service share a shell, not repeated text. Articles retain
translated identities, shared typography/navigation and RTL.

Public narrow layouts stack information, expose a menu, preserve tables/media.
Backend narrow layout is out of scope. Keyboard focus, family switching, gallery
state, loading/error feedback and reduced motion are acceptance requirements.

Observed checks and unfinished publication work are recorded in the execution
ledger. This decision record is not a completion verdict.
