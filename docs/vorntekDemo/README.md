# Vorntek 工业企业内容包

Vorntek 是通用网站与业务系统中的虚构工业 B2B 企业。软件没有固定的工业业务枚举；此目录是可替换的品牌、目录、编辑内容、媒体与模板。

- `catalog.json`：三个系列、六种设备、三个应用方案。外形尺寸按宽/高/深、毫米保存，与原创三维模型一致。
- `pages.json`：公司、技术、服务与三篇技术指南的中英文内容。
- `articles.json`：中、英、阿三种语言的工业文章，保留旧文章关联标识和书签路径，通过现有文章编辑与受控发布流程使用。
- `templates/`：共享框架、产品详情和编辑页面模板。
- `assets/`：既有品牌、原创设备模型、同源渲染图/结构视频与生成应用照片。来源见 [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md)。
- `archive/catalog-v2.json`：历史内容，不是当前构建输入。

旧素材与历史出版物不无差别删除。当前设备目录不再使用历史沟通插画；模型与应用照片各有用途，不能把概念照片当成精确尺寸依据。

构建：在产品仓库根目录运行 `python scripts/build_vorntek_site.py`，也可用 `--catalog PATH --output DIRECTORY` 构建独立静态产物。默认生成38条HTML路由、六份文本规格与产品3D槽位声明；数量不是底层软件限制。脚本不清空输出、不改数据库、不发布网站。正式发布仍经文章预览、不可变整站候选、选版与部署机制完成。

表单字段与校验以真实后台配置为准，产品上下文不改变表单规则。官网正常支持手机浏览；后台按PC使用。演示性质集中说明于 `/demo/`，不混入企业宣传正文。当前实现与验收状态见 [执行记录](../CORPORATE_WEBSITE_EXECUTION.md)，文件生成不代表已上线或完成外部投递。
