# Vorntek 中性示例内容与素材

当前默认网站是全行业通用的虚构示例，不是真实企业宣传。内容在 [catalog.json](catalog.json)，目录标识不再与旧后端业务枚举绑定。目录可为空、两条或更多条；列表、详情、双语、真实配置表单、合成图表及CSV功能保留。

- [素材预览](review-board.html)：保留品牌Logo与三张新作中性SVG。可放大、选择与下载；隐藏仅影响当前素材预览，不删除文件。
- [内容约定](brandBrief.md)：示例定位、文案与操作边界。
- [Logo来源](imageGeneration.json)：原始生成元数据按原样保留；历史提示词不是当前产品行业范围。

SVG是说明插图，不是客户照片、实物或已完成的系统状态。原七张旧业务概念图和旧详情退出当前候选，可从升级前Git历史恢复；没有删除线上运行文件或用户资产。

构建：`python scripts/build_vorntek_site.py`。也可用 `--catalog PATH --output DIRECTORY` 构建独立静态产物。脚本不会清理目标中的其他内容；部署必须使用审核过的完整候选，不把覆盖式生成当作旧内容清理。

独立数据库示例见通用示例数据包及其导入说明；本目录只提供可选网站内容，不创建账号、借用凭据、激活平台或证明外部投递。页面默认禁止搜索引擎索引；表单保存取决于真实后端配置与提交结果。
