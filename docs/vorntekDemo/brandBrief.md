# Vorntek 工业B2B内容约定

产品是全行业通用的网站与业务管理软件。Vorntek只是独立实战环境的虚构示例身份，不是固定的制造商或行业模板。

Vorntek Industrial Systems / Vorntek 工业系统提供检测、模块化装配、物料流转及产线数据集成方案。面向工程师、采购与项目负责人，按认识企业—查找设备—理解应用—查看资料—沟通需求组织官网。此前中性咨询站及办公空间方向均已由用户确认的工业定位替代。

正文围绕用途、工件条件、定位、接口、换型、维护和规格编写，各页有独立任务。必要演示说明集中于专页；表单用途、隐私与实际提交结果保持准确。不冒用真实客户、资质、销量、人物、地址或联系方式。

保留Vorntek标志及蓝/深蓝/白识别；工业照片解释生产环境，原创模型及同源渲染图辨认具体设备。不用测试球体或三角形冒充设备，不把概念照片当精确尺寸依据。外部接入保持关闭；不借用香港资料或凭据，不改香港运行。

网站目录和表单定义分离：修改目录不能强制改变后端必填字段。表单通过现有配置接口加载，启用/必填/标签/选项的权威来源为后台配置。公开网站保留正常手机浏览；后台按PC使用。

内容管理、预览、选版与受控部署依旧是软件功能，不因替换示例素材而删除。私有预览不公开，不代表真实外部闭环已通过。
