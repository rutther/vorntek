# 广告系列操作示意图

`meta-campaign-guide.svg` 是项目自行绘制的中性操作示意图，不是客户截图，也不是当前账号的广告设置或发布证据。所有名称均为虚构示例。

源数据在 `fixtures/guide-figures.json`，由 `scripts/build-guide-figures.mjs` 在测试、构建前生成。修改源数据后重新构建，不直接维护打包目录。图示保留系列、广告组、广告三个层级与网站获客设置的核对位置。

入口和交互沿用现有引导：点击“图示”打开，可查看大图，关闭按钮或 Esc 退出。实际配置必须以使用者自己的 Meta 账号为准，不能按示例名称判断完成。
